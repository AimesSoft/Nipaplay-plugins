# danmaku_regex_filter — 弹幕正则过滤规则预设

内置常用弹幕正则过滤规则，启用后自动屏蔽匹配的弹幕。

## 包含规则

| 规则 | 说明 |
|------|------|
| 刷屏重复 | 重复字符、笑声刷屏、短语重复、超长弹幕（≥40字） |
| 刷观看次数 | "二刷""三周目"等刷存在感弹幕 |
| 日期考古 | 内嵌或整条的日期弹幕（`2026.04.12`、`7/9/2012`、`2026-04-12`、`20260412`、`260619`、`0922`、`06/19`、`6月19号`、`2026年4月12日`、`12。03`、`11,.10.21`、`2011_7_24`、`2012y7m28d`、`23 12 30` 等），以及日期叠加"补完/存活/留念"等（如 `11.5.28补完`、`存活 6.3`） |
| 打卡占位 | 整条仅由"补完/完结/撒花/存活/留念/留恋/纪念/留名/考古/签到/打卡/周目"等打卡词与标点、数字组成、无实际内容的占位弹幕（`补完纪念`、`完结撒花`、`存活确认`、`留名`、`留念` 等）；带情感的如"补完了，值了啊"不受影响 |
| 加群宣传 | "交流群""加群""QQ群"及带群号数字串的宣传弹幕 |
| 有人在看吗 | "有没有人""有人在看吗"等无意义弹幕 |
| 纯关键词 | "路过""打卡""前排""签到/签"等占位型弹幕及纯短数字 |

## 使用方法

在 NipaPlay 插件设置中启用本插件。每条规则支持独立开关，可在设置页中逐条切换。

## 规则来源

规则参考自社区整理的弹幕过滤方案。

## 更新日志

### v1.3.0

- **重写 日期考古**：改为允许日期出现在弹幕任意位置（不再要求整条匹配），并基于真实弹幕数据扩充格式覆盖
  - 新增分隔符：中文句号/顿号/逗号/下划线（`12。03`、`2012,，2月,26号`、`11,.10.21`、`2011_7_24`）
  - 新增 `月/日/年` 顺序（`7/9/2012`）、空格分隔年月日（`23 12 30`）、字母年月日（`2012y7m28d`）
  - 新增 4 位月日紧凑（`0922`）与 4/5 位年份容错（`20125-8-21`、`20013.11.9`）
  - 新增"日期 + 打卡词"组合（`11.5.28补完`、`存活 6.3`、`6.12…补完`）
  - 紧凑数字用 `\b` 限定，避免误伤 `2333`、`10086`、`11111东方` 等
- **新增 打卡占位**：屏蔽整条仅由"补完/完结/撒花/存活/留念/留恋/纪念/留名/考古/签到/打卡/周目"等打卡词与标点、数字组成的占位弹幕；带情感的如"补完了，值了啊""完结了…真可惜"不受影响

### v1.2.3

- **增强 日期考古**：扩展常见日期格式覆盖，新增两位年份日期（`26/06/19`）、6 位紧凑日期（`260619`）、年月格式（`2026/6`）、月日格式（`06/19`、`6-19`）、中文 `号` 写法（`6月19号`）和日期时间写法（`2026/6/19 12:30`、`2026-6-19 12点30`）
- **优化 日期考古**：仍保持整条弹幕匹配，避免误伤包含日期但有实际内容的弹幕（如 `2026/6/19 前方高能`）
- **增强 刷观看次数**：新增包含匹配 `首刷`，只要弹幕内容包含 `首刷` 即会屏蔽；不扩展匹配 `首次观看`、`首遍` 等其它表达

### v1.2.2

- **修复 日期考古**：支持 `2026/6/19` 等斜杠日期格式
- **修复 日期考古**：正则内部使用 `\\x2f` 匹配 `/`，避免和插件 `名称/正则/` 外层分隔符冲突导致规则被截断

### v1.2.1

- **增强 日期考古**：新增紧凑日期格式——`20260412`（8 位连写）、`2026.0412`/`2026.412`（年.月日连写）、`26.04.12`（两位年份）、`2026年4月`（无日）等
- **新增 加群宣传**：屏蔽 "交流群""加群""QQ群""粉丝群""入群/进群" 及 "群123456"、"QQ：123456" 等带群号数字串的宣传弹幕（"一群人""群众"等正常用语不受影响）
- **增强 纯关键词**：补充 "签/签到/签个到/已签到" 等签到类占位弹幕

### v1.2.0

- 初始规则集：刷屏重复、刷观看次数、日期考古、有人在看吗、纯关键词
